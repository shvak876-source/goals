# מטרות היום

אפליקציית מטרות יומית בעברית, בסגנון אפליקציות אפל עם תפריט Liquid Glass.

- מטרות ותתי־מטרות עם סימון בעיגול
- ברכה לפי שעה (בוקר / צהריים / ערב / לילה טוב) ותאריך לועזי ועברי
- מטרות שחוזרות כל יום
- היסטוריה: ריבועי השלמה, רצף ימים, שיא רצף וסיכום 7 ימים
- עובדת בלי אינטרנט ונשמרת במכשיר

## התקנה באייפון
1. פותחים את כתובת האתר ב-Safari.
2. לוחצים על כפתור השיתוף ← "הוספה למסך הבית".

## פיתוח
עורכים את `src/app.html` ומריצים `./build.sh` כדי לבנות את `index.html`.
